# Fiore Note（フィオーレ ノート）

1人サロン向けの、シンプルな施術記録アプリ（試作版）です。
お客様の名前と施術内容だけを記録し、過去の施術履歴をすぐに確認できます。

- ログイン不要・月額料金なし・インターネット通信なし
- データはスマホ／パソコンの **ブラウザの中だけ** に保存されます
- HTML・CSS・JavaScript だけで作られています（インストールするソフトは不要）

---

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（これを開くとアプリが起動します） |
| `style.css` | 見た目（白と淡いピンクのデザイン） |
| `app.js` | 動き（登録・検索・保存・バックアップなど） |
| `manifest.json` / `icon*.png` / `icon.svg` | スマホのホーム画面に追加したときの名前とアイコン |

## 使い方

### 1. お客様を登録する
1. 一覧画面の下にある **「＋ お客様を登録」** を押します。
2. お名前またはニックネームを入力し、**「保存」** を押します。
   （メモ欄は任意です。好みの圧など、ずっと覚えておきたいことに使えます）
3. 登録すると、そのままお客様の施術記録画面に移ります。

### 2. 施術記録をつける
1. お客様の画面で **「＋ 施術記録を追加」** を押します。
2. 来店日は **今日の日付が自動で入っています**（変更もできます）。
3. 施術メニューを入力します。2回目からは、過去に入力したメニューが
   **ボタンで表示される** ので、タップするだけで入力できます。
4. 「施術内容・身体の状態・次回へのメモ」を書いて **「保存」** を押します。

記録は **新しい日付順** に並びます。

### 3. お客様を探す
一覧画面の上の検索欄に名前の一部を入力すると、すぐに絞り込まれます。
ひらがな・カタカナ、全角・半角の違いは区別しません（例：「さくら」で「サクラ」も見つかります）。
一覧は **最近来店した順** に並んでいます。

### 4. 編集・削除
- お客様情報：お客様画面右上の **「編集」** → 内容を直して「保存」、または一番下の「このお客様を削除」
- 施術記録：各記録の **「編集」** → 内容を直して「保存」、または一番下の「この記録を削除」
- 削除の前には必ず確認が表示されます。お客様を削除すると、そのお客様の施術記録もすべて削除されます。

### 5. バックアップと復元（とても大切）
右上の **⚙（設定）** から行います。

- **バックアップ**：「バックアップファイルを保存」を押すと、
  `fiore-note-backup-年月日-時刻.json` というファイルが保存されます。
  - iPhone：「ファイル」アプリの「ダウンロード」フォルダなどに保存されます
  - Android：「ダウンロード」フォルダに保存されます
- **復元**：「バックアップファイルを選ぶ」から、保存しておいたファイルを選びます。
  内容（件数・作成日時）を確認したうえで、**今のデータと置き換わります**。
- 機種変更のときは、古い端末でバックアップ → 新しい端末にファイルを移す → 復元、の順で移せます。

> **週に1回程度はバックアップしてください。** 設定画面に「前回のバックアップ日時」が表示されます。

### 6. お試し用データ
設定画面の「サンプルデータを追加」で、架空のお客様3名・施術記録5件を追加できます。
試し終わったら、各お客様を削除するか「すべて削除する」で消してください。

## パソコンで試す方法

1. このフォルダを丸ごとパソコンにダウンロードします
   （GitHub の画面なら「Code」→「Download ZIP」→ 解凍）。
2. `index.html` をダブルクリックすると、ブラウザでアプリが開きます。

※ パソコンで入力したデータはパソコンのブラウザにだけ保存され、スマホとは共有されません。

---

## スマホで使う方法

スマホで使うには、アプリのファイルを **インターネット上の置き場所（Webサーバー）** に置き、
スマホのブラウザでそのアドレスを開く必要があります。
（ファイルを置くだけで、**お客様のデータはサーバーには送られず、各スマホの中にだけ保存されます**）

### おすすめ：GitHub Pages（無料）を使う方法
1. GitHub のこのリポジトリ画面で **Settings → Pages** を開きます。
2. 「Branch」で公開したいブランチ（例：`main`）と `/ (root)` を選んで **Save**。
3. 数分後、`https://（ユーザー名）.github.io/treatment-records-app/` のようなアドレスが表示されます。
4. そのアドレスをスマホで開きます。

> 注意：GitHub Pages は **誰でもアクセスできる公開ページ** になります。
> アプリの「入れ物」が公開されるだけで、お客様のデータは公開されませんが、
> リポジトリにお客様の情報やバックアップファイルを **絶対にアップロードしないでください**。
> （無料プランでは、Pages を使うにはリポジトリを公開設定にする必要がある場合があります）

### ホーム画面に追加する（アプリのように使う）
- **iPhone（Safari）**：画面下の共有ボタン（□に↑）→「ホーム画面に追加」
- **Android（Chrome）**：右上の「︙」→「ホーム画面に追加」または「アプリをインストール」

ホーム画面に追加すると、アイコンから1タップで起動でき、
iPhone ではデータが自動で消されにくくなります。**必ずホーム画面に追加して使ってください。**

> 注意：Safari で開いたものと、ホーム画面のアイコンから開いたものでは、
> **データの保存場所が別々** になる場合があります。いつも同じ方法で開いてください。

## 実装しなかった（できなかった）機能・制限

- **オフライン起動（電波がない場所での起動）**：今回は仕組みを簡単にするため未対応です。
  一度開いた後はブラウザのキャッシュで開けることが多いですが、保証はされません。
  （データ自体は端末内にあるので、通信がなくても記録の保存はできます）
- **アプリ自体のパスワードロック**：未実装です。端末のロックで守る前提です。
- **データの暗号化**：保存データ・バックアップファイルともに暗号化されていません。
- **複数端末での同期**：クラウドを使わない方針のため未対応です（バックアップファイルで手動移行）。
- **自動バックアップ**：ブラウザの制限で自動保存はできません。手動で行ってください。
- **実機での確認**：開発環境の制限により、実際の iPhone / Android 実機では確認していません。
  iPhone・Android の画面サイズを再現した自動テスト（Chromium）で、
  登録・記録・検索・編集・削除・再読み込み後のデータ保持・バックアップ・復元・不正ファイルの拒否を確認しました。
  お使いのスマホで、まずサンプルデータで一通り試してください。
- 要望により、住所・電話番号・メール・生年月日・予約・売上・決済・外部連携・写真は入れていません。

## ⚠ データ保存についての大切な注意

- データは **この端末の、このブラウザの中だけ** に保存されます（`localStorage` という仕組み）。
- 次の場合、**データが消えることがあります**：
  - ブラウザの「履歴とWebサイトデータを消去」「閲覧データの削除」をした
  - ブラウザを削除・初期化した、端末を初期化・修理・紛失した、機種変更した
  - プライベートブラウズ（シークレットモード）で使った
  - iPhone の Safari で、ホーム画面に追加せずに長期間（約7日）開かなかった
  - 端末の空き容量が非常に少なくなった
- だからこそ、**定期的なバックアップ** と、バックアップファイルを
  **端末以外の場所（パソコンなど）にも保管** することが大切です。

## ⚠ 実際のお客様情報を扱う前に必要な安全対策

施術記録には「身体の状態」など、**健康に関わる配慮が必要な個人情報** が含まれる可能性があります。
端末内に保存しているからといって、**安全性が保証されるわけではありません**。

### 端末の管理
1. スマホに **パスコード＋顔認証/指紋認証** を必ず設定し、自動ロックを短め（1分など）に。
2. サロン専用の端末にするか、家族などと共用しない。
3. 「iPhoneを探す」「デバイスを探す」を有効にし、紛失時に遠隔でロック・消去できるようにする。
4. OS とブラウザを常に最新にする。怪しいアプリを入れない。

### 記録内容の工夫
5. お名前はフルネームでなく **ニックネームやイニシャル** でも運用できます。
6. 施術に必要のない情報（病名の詳細、プライベートな事情など）は書かない。

### バックアップファイルの管理
7. バックアップファイルは **暗号化されていない** ため、誰でも中身を読めます。
   - LINE やメールで送らない、共有フォルダに置かない、GitHub に上げない
   - パソコンに保存する場合は、パソコンにもパスワードをかける
   - パスワード付きZIPや、暗号化されたUSBメモリでの保管を検討する
   - 古いバックアップは定期的に削除する

### お客様への説明（個人情報保護法）
8. 個人情報保護法は、1人で営業しているサロンにも適用されます。
   - 「施術の記録のために、お名前と施術内容・お身体の状態を記録します」と **利用目的を伝え**、
     特に身体の状態の記録については **お客様の同意** を得ておくと安心です。
   - お客様から記録の開示や削除を求められたら対応できるようにしておく。
   - 万一、端末の紛失などで情報が漏れた可能性がある場合の連絡先・対応を考えておく
     （個人情報保護委員会のWebサイトに事業者向けの案内があります）。

### 販売を考える場合
他のサロンに販売する場合は、上記の説明書きに加えて、利用規約・免責事項、
アプリのパスワードロックや暗号化の追加、実機での十分なテスト、
不具合時のサポート体制などを検討してください。

## 開発者向けメモ

- データは `localStorage` の `fioreNote.data.v1` に JSON で保存しています。
- `index.html` の Content-Security-Policy で外部への通信（`connect-src 'none'` など）を禁止しています。
- 画面に表示する文字はすべて `textContent` で入れており、入力内容が HTML として実行されないようにしています。
- 外部ライブラリは使っていません。
